# Agentic AI Browser Agent R&D

This repository contains research and experiments for agentic AI browser agents.

## Structure

```text
Research/
  Product/
    <research-study>/
      README.md
  Technical/
    <research-study>/
      README.md
Experiments/
  <experiment>/
    README.md
```

- **[Product Research](Research/Product/):** User needs, use cases, product ideas, and market research.
- **[Technical Research](Research/Technical/):** Architecture, tools, methods, and technical investigations.
- **[Experiments](Experiments/):** Prototypes, trials, and evaluations.

Every research study and experiment must have its own separate directory. Read [AGENTS.md](AGENTS.md) for the repository organization rules.

Before starting product research, read the [product research skills guide](Research/Product/SKILLS.md). Tell the user which skill you will use and why.
